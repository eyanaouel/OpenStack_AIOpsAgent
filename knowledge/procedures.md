# Procédures Standard

## Création VM Standard
1. Vérifier les quotas
2. Choisir le flavor approprié
3. Sélectionner l'image de base
4. Configurer le réseau
5. Ajouter une clé SSH
6. Surveiller le démarrage

## Déploiement Application Web
1. Créer la VM avec Ubuntu
2. Exécuter le playbook install_nginx.yml
3. Configurer le firewall
4. Tester l'accès HTTP
5. Configurer le monitoring

## Maintenance Mensuelle
1. Vérifier l'état de toutes les VMs
2. Nettoyer les VMs en erreur
3. Confirmer les redimensionnements en attente
4. Mettre à jour les images de base
