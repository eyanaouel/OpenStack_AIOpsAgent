# Guide de Dépannage OpenStack

## VMs en Erreur
- Vérifier les quotas disponibles
- Vérifier la connectivité réseau
- Consulter les logs Nova
- Redémarrer en mode HARD si nécessaire

## Problèmes de Réseau
- Vérifier les security groups
- Tester la connectivité avec ping
- Vérifier les règles de routage

## Performance Lente
- Vérifier l'utilisation CPU/RAM
- Optimiser les flavors
- Considérer la migration vers un compute node moins chargé
